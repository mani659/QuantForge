## 9. MODERN-SCOPE REVIEW AND SIGN-INVERSION TEST (REVISED)

(SELECTION REVIEW — the load-bearing correction)

**Forward justification for a modern daily liquid US-equity decision *context*** is real and preserved: only the future is tradeable; the modern era carries current execution environment, cost structure, market structure, data availability, and future tradability. A modern daily-equity reference *context* survives sign inversion.

**But the sign-inversion test applies to the proposed *selection*, and at that level it FAILS.** Constructed from repository evidence, not intuition:

1. **Trigger dependence.** The specific trigger — long after a prior-day return in the lowest tercile of the trailing 11-day block — descends from the H01 volatility-asymmetry hypothesis. No repository artifact proposes, values, or tests this rule before or independently of the H01 arc. Its directional content rests on H01's adjudicated scientific support, which is itself an H01 outcome; for the broad-US contemporary markets (two of the four proposed), that support shares the very window whose economics are favorable.
2. **Counterfactual test.** If H01's contemporary economics had been negative, the rule's measured decision economics would be negative in **both** evaluated eras after realistic costs (−0.14%/day historical; the hypothetical negative contemporary). Would QuantForge then select this rule as the first Base? The repository evidence answers NO: (a) no priority rationale would favor a twice-measured-negative process for the *first* validation slot; (b) the only remaining arguments — completeness, pre-frozen rule, clean attribution — are validity properties that hold for any properly registered rule and do not select this trigger; (c) selecting it anyway, as the anchor for conditional research, would be substantively indistinguishable from the rescue framing V38A's viability standard ("not deliberately selected because it is deeply negative") and BS13 prohibit.
3. **V1-r1's disclosed admission was the defect.** "The context survives; the signal does not" is not a partial pass — it is a positive demonstration that the *signal* (the object being selected) was selected because of H01's results. Under BS6, a hypothesis whose selection depends on the motivating result must not be advanced; the fresh-data feasibility (post-2026-08-14 observations) is a *registration-time* condition that cannot cure a selection-time dependence (the revision mandate §4).

**Result: FAIL.** The proposed scope's *context* is forward-justified; the *selection of this rule within it* is outcome-dependent. BH-01 in any form preserving the H01-descended trigger is not an independently justified Base hypothesis.
