## 5. Counterfactual Governance Lesson
A strong absolute treatment result is insufficient when the registered condition does not improve the closely related counterfactual. A profitable mechanism event is not a valid component artifact if its specific constraint destroys value. CAND-055 is the canonical example of this Type 1 failure mode.

## 6. Event Economics vs Condition Value
A condition can fail as an economic mechanism even when the underlying event itself is profitable. 
- **EVENT ECONOMICS:** What happens when the event occurs? (e.g., Fading the Initial Balance is profitable).
- **CONDITION VALUE:** Does the specific condition improve the event distribution? (e.g., Demanding a false breakout first makes the distribution *worse*).
Only the condition value establishes incremental mechanism value.
